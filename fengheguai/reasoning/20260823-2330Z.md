This trial returns to the pattern that has actually produced champions here. The two most valuable mechanisms in this model are both per-layer and per-token: the value embeddings inject token identity into each layer's value path, and the attention output gate lets each head decide per token how much of its output to emit. The x0 path is the one place where a per-layer quantity stayed token-blind. Every layer re-injects the normed token embedding as resid_lambdas[i] * x + x0_lambdas[i] * x0, and x0_lambdas is a learned scalar per layer, so every token at layer i gets back exactly the same fraction of its own embedding. That is the same gap t0372 found in the MLP path, except that closing it there cost 50.3M parameters and closing it here costs 1536.

**Change.** One mechanism added to champion t0379. GPT gains x0_gate, a ModuleList of one bias-free Linear from 128 channels to 1 per layer, and the residual mix becomes resid_lambdas[i] * x + (x0_lambdas[i] * g0) * x0 where g0 is 2*sigmoid(x0_gate[i](x[..., :128])). The gates are zero-initialised so 2*sigmoid(0) is exactly 1.0 and the model is identical to the champion at step 0. The gate parameters join x0_params, the AdamW group that already holds x0_lambdas, rather than matrix_params: a (1, 128) weight under Muon would be orthogonalised by Newton-Schulz to unit norm, which would destroy the magnitude the gate exists to encode. Everything else is untouched, including both squared decay profiles, the value embeddings, the attention gate and the 300-step momentum warmup.

**Predicted effect.** Expected between 0.9610 and 0.9635 against champion 0.962349. The added work is one 128-by-1 matmul and a sigmoid per layer, then a scalar-by-tensor multiply folded into a residual mix that was already doing two of them; the mix is pointwise and is consumed by the norm at the top of the block, which is also pointwise, so by the corrected fusion rule from t0382 this should fuse and cost nothing. Steps within noise of 2772 would confirm that reading. A decrease says token-blind re-injection was leaving something on the table and the follow-up is whether resid_lambdas wants the same treatment. A null says x0_lambdas alone was sufficient, which given how cheap this is would mean the per-token pattern is not general but specific to the value and attention paths.

**Stated risk.** The gate multiplies a quantity that is already small, since x0_lambdas initialises at 0.1, so the mechanism has limited room to act and a null may reflect scale rather than principle; if it lands within noise I will not tune the gate width or its init, I will read it as x0 being a minor path. The more interesting failure is that x0 is the same tensor at every layer, so twelve independent gates on one source could learn to fight each other in a way the single scalars could not, which would show as a regression larger than the mechanism could plausibly cost.
