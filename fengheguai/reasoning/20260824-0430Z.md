**Hypothesis (pre-registered).** Attention placement matters at constant attention budget. The model spends its attention through a periodic tile, WINDOW_PATTERN='SSL' over 12 layers, which puts a full-context layer at 2, 5, 8 and 11 and a 256-token local window everywhere else. Every trial on this axis so far has moved the AMOUNT of global attention -- the short span, the long span, the ratio -- and all three directions peaked, so the axis reads as closed. But amount and position are different questions and only the first has been asked. Because _compute_window_sizes indexes pattern[layer_idx % len(pattern)], a 12-character pattern makes the modulo tile the identity and gives exact per-layer control, and holding the count of long layers at 4 holds attention FLOPs and kernel work exactly fixed. This trial moves the four long layers from uniformly spread to contiguous at the top: SSSSSSSSLLLL. The bet is that the uniform tile is an unexamined default rather than a tuned choice, and that a network which builds local features first and integrates globally last uses the same budget better than one that interrupts local processing every third layer. It is the same 'shape is a free axis' bet that has now won four times on decay schedules, applied to the one remaining structure that is laid out uniformly by default.

**Change.** One string literal: WINDOW_PATTERN 'SSL' -> 'SSSSSSSSLLLL'. No new tensors, no new operations, no change to any per-step code path. The effective per-layer window assignment goes from SSLSSLSSLSSL to SSSSSSSSLLLL; both have exactly 4 long layers out of 12 (the model forces the last layer long in either case), so estimate_flops is unchanged and the step count should be unchanged. The edit script asserts the L count is preserved and refuses the edit otherwise, so a budget change cannot slip in disguised as a placement change.

**Predicted effect.** Genuinely uncertain in sign, which is why it is worth a trial. Throughput cost is zero by construction, so the whole raw delta is mechanism and the ~0.0012 n=1 floor applies to it directly rather than to a corrected residual. I will read the step count first: this change cannot legitimately move it, so a step delta beyond about 0.5% means contention and voids the comparison regardless of the score. If placement is a real axis I expect something in the -0.001 to -0.003 range; if the uniform tile is already near-optimal I expect a small loss, since contiguous-late is the maximal-contrast arrangement and should overshoot in whichever direction the axis runs. Either outcome resolves the direction and tells me whether to spend further trials on intermediate arrangements.

**Stated risk.** Low implementation risk: a single string constant, validated by ast.parse and by an assertion that the long-layer count is preserved. The real risk is interpretive. First, the last layer is forced long independently of the pattern, so 'contiguous at the top' is partly the model's own doing and an all-S pattern would not actually produce an all-local network -- I am not treating the forced layer as part of my manipulation. Second, a null result on this single maximal-contrast arrangement is evidence about THAT arrangement, not about placement in general; three linear extrapolations have already failed in this campaign and I will not read a single permutation as closing the axis. Third, equal FLOPs is not automatically equal wall-clock, since contiguous same-window layers may schedule differently from alternating ones; the step count check catches that and I will attribute rather than assume.
